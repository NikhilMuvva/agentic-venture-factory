# Structured Agent Output

## Status
Accepted

## Context

TestForge creates standardized-test practice material that must be validated and stored consistently.

## Decision

Represent agent outputs with structured data that can be parsed, verified, stored, and reused by deterministic components.

## Alternatives

Free-form natural language outputs with manual interpretation.

## Consequences

Structured output supports validation and repeatable processing. It can increase prompt and schema design effort.
