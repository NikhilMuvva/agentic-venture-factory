# AVF — Agentic Venture Factory

AVF is an experimental modular framework for constructing, operating, and studying autonomous agent-driven digital ventures.

## Layers

1. AVF Core

   Reusable orchestration, model routing, governance, memory, event handling, and observability.

2. Shared Services

   Reusable functions such as sales, analytics, marketing, and research.

3. Ventures

   Independent businesses built on the common AVF infrastructure.

4. Experiments

   Controlled studies evaluating cost, reliability, autonomy, and architecture.

5. Research

   Methodology and results intended to support eventual publication.

## Current Ventures

### Venture 001 — TestForge

TestForge creates and validates original standardized-test practice material using multiple specialized agents, deterministic verification, and structured visual generation.

## Status

Experimental.

The system is not yet claimed to be fully autonomous.
